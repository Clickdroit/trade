# 6. Journal et suivi

## Journal des trades (fichier CSV)

| Colonne | Exemple |
|---|---|
| date_heure | 2026-11-20 14:00 |
| signal | ACHAT |
| prix | 94250.00 |
| quantite | 0.001 |
| frais | 0.09 |
| resultat | +1.2 % |
| raison | croisement MM10/MM30 |

## Bilan hebdomadaire
Chaque semaine, noter :
- Nombre de trades et résultat total
- Meilleur et pire trade
- Erreurs ou plantages
- Ce qu'on améliore la semaine suivante

## Indicateurs de suivi
- Solde du compte fictif
- Taux de trades gagnants
- Perte maximale (drawdown)
- Temps de fonctionnement du bot sans erreur
